# ai-tools — one working tool per video

Tools built on the **Build, Break, Fix** YouTube channel. Each folder is one video: a small Python tool you can run
(or a Windows app you can install from [Releases](https://github.com/Berdun/ai-tools/releases)), the tests, and the measuring script behind the numbers in the video.

| # | Tool | What it does | Video |
|---|---|---|---|
| 01 | [chat-with-your-documents](01-chat-with-your-documents/) | Ask questions about your own PDF; answers cite the page and never make things up. Free, runs on your computer (Ollama). | coming soon |

Everything runs locally unless the README of a tool says otherwise. Course with the full system around these tools: link in each video's description.
